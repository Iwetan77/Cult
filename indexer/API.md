# Indexer read API

The indexer (Envio HyperIndex) exposes a GraphQL API over the entities in
`schema.graphql`. Backend consumes it to fill `Member.winRate` /
`Member.realizedPnlUsd` / `Member.tradeCount` and the public share cards. This is
the canonical description of what those entities mean; the GraphQL surface itself
is generated by Envio from `schema.graphql`.

## Units — never combined silently

- **Perpl** PnL is AUSD. Raw fields are `*CNS` = AUSD * 1e6 (signed).
- **Nad.fun** PnL is native MON. Raw fields are `*MonWei` = MON * 1e18 (signed).
- `Trader.realizedPnlUsd` is Perpl AUSD only. `Trader.realizedPnlMon` is Nad.fun
  MON only. The indexer does **not** add MON to AUSD. A combined AUSD figure needs
  a MON price at each event's time; the backend owns that conversion and serves
  the display value. There is no per-event MON price recorded on-chain here.
- Timestamps (`openedAt`, `closedAt`, `firstTradeAt`, `lastTradeAt`) are epoch
  **milliseconds**.

## Entities

| Entity | Key | What it is |
|--------|-----|-----------|
| `Trader` | `id` = lowercase wallet | aggregate stats, both venues |
| `PerplAccount` | `id` = Perpl account id | account id -> owner wallet |
| `Trade` | composite | a closed Perpl round trip |
| `PositionEvent` | `tx-logIndex` | raw Perpl position lifecycle event |
| `NadFunTrade` | composite | a closed Nad.fun round trip |
| `NadFunEvent` | `tx-logIndex` | raw Nad.fun router Buy/Sell |

## Stat definitions

**A trade** is a round trip: a Perpl position opened then fully closed (size back
to 0), or a Nad.fun token bought back to a zero balance.

**Win rate** = profitable closed trades / total closed trades, across both venues.
A trade is a win when its realized PnL is positive (in its own unit).

**Realized PnL, Perpl** = sum of the contract's reported `deltaPnlCNS + fundingCNS`
across every close-type position event (`Decreased`, `Closed`, `Liquidated`,
`Deleveraged`, `Inverted`); `Unwound` contributes `positionFmvCNS`.

**Realized PnL, Nad.fun** = average-cost per (wallet, token), in MON wei:
- Buy: `qty += amountOut`, `cost += amountIn` (amountIn = MON wei, amountOut = tokens)
- Sell: `realized += amountOut - cost * amountIn / qty`, then
  `cost -= cost * amountIn / qty`, `qty -= amountIn` (amountIn = tokens, amountOut = MON wei)

**"Recent" PnL** is derived at query time: filter the trade lists by `closedAt`.

## Example query

```graphql
query MemberStats($addr: String!) {
  Trader(id: $addr) {
    tradeCount
    winningTrades
    losingTrades
    winRate
    realizedPnlUsd
    realizedPnlCNS
    realizedPnlMon
    realizedPnlMonWei
    nadFunTrades(order_by: { closedAt: desc }) {
      token
      qtyRaw
      costMon
      proceedsMon
      realizedPnlMon
      isWin
      origin
      openTx
      closeTx
      openedAt
      closedAt
    }
  }
}
```

## Correlating with the backend (clan labels + mirror vs own)

The backend tags mirror/stack activity so the indexer can tell it apart from a
member's own trades. It exposes (with header `X-Indexer-Key`):

- `GET /v1/indexer/accounts` -> `{ accounts: [{ userId, wallet, perplAccountId, clanIds }] }`
- `GET /v1/indexer/orders?since=<ms>` -> Perpl orders, `kind: mirror_open | mirror_close | stack_open`
- `GET /v1/indexer/trades?since=<ms>` -> leader trades with `tradeId`, `perplAccountId`, `openTx`, `venue`, `market`
- `GET /v1/indexer/txs?since=<ms>` -> `{ txs: [{ venue, txHash, wallet, kind, refId, clanId, tradeId, createdAt }] }`

**Perpl** — `OrderRequest(perpId, accountId, orderDescId, …)` carries `orderDescId`
= the backend's `requestId`. A fill whose `(accountId, orderDescId)` appears in
`/orders` is a mirror/stack; anything else on a clan member's account is their own.
Map `accountId` -> member/clans through `/accounts`.

**Nad.fun** — the backend tags its mirror/stack buys and sells by tx hash. The
indexer exposes `NadFunTrade.openTx` / `closeTx` and a nullable `NadFunTrade.origin`
(`null` = member's own, `"mirror"`, `"stack"`). The label is set by joining the
trade's `openTx` against `/v1/indexer/txs` (venue=`nadfun`, `kind`):
`mirror_open` -> `"mirror"`, `stack_open` -> `"stack"`.

## Known gaps (reconcile before shipping the "verified" badge)

- Perpl funding settled on position *increase* (`PositionIncreased.premiumPnlSettledCNS`)
  is not counted. Second-order (funding only).
- Perpl raw fills (`MakerOrderFilled` / `TakerOrderFilled`) are not indexed; the
  position-level history covers the "real timestamped list" requirement.
- Nad.fun token transfers in/out of a wallet (not via the router) change qty with
  no price. They are treated as zero-cost-basis on the next sell; the token
  `Transfer` event is not yet indexed to flag them explicitly.
- `NadFunTrade.origin` is stored as `null` until the indexer/backend runs the
  `/v1/indexer/txs` join above.
